# 示例课程文档

> 本文档展示一篇文章的推荐格式，以后你可以参考这个模板来写笔记。

## 一、标题

使用 `##` 表示二级标题，`###` 表示三级标题，以此类推。`#` 是一级标题，一般每篇文档只用一次（最上面那个）。

## 二、正文

正文直接写就好，每写完一段就空一行（按一下回车换行）。

**这是加粗的文字**，*这是斜体的文字*。

## 三、列表

无序列表用 `-` 开头：

- 第一项
- 第二项
  - 嵌套项目（前面多几个空格）
- 第三项

有序列表用数字开头：

1. 第一步
2. 第二步
3. 第三步

## 四、代码

行内代码用反引号包裹，比如 `print("hello")`。

代码块用三个反引号包裹，并写上语言名：

```python
def hello():
    print("Hello, world!")
```

```bash
echo "这是一个命令行"
```

## 五、引用

> 用 `>` 开头表示引用。
>
> 多行引用可以在每行前加 `>`。

## 六、链接与图片

- 外部链接：`[链接文字](https://example.com)`
- 内部链接：`[跳转到笔记首页](index.md)`
- 图片：`![图片说明](图片地址)`

## 七、分割线

三个或更多短横线：

---

## 八、表格

| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |

---

这就是一篇标准笔记的基本格式了。你只需要打开一个新 `.md` 文件，照这个格式写就行。
